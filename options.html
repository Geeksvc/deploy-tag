Deploy Tag

Shows which tool, launchpad or operator made a token, read from its metadata URI. Works on Solana and EVM chains (BSC, Robinhood, Base, Ethereum, Avalanche). Clicking a badge opens the token on its explorer.

Helius API key SOL

Free at dashboard.helius.dev. Stored only in this browser.

Alchemy API key

One key covers every EVM chain below. Free at dashboard.alchemy.com; turn each network on for your app. A chain that isn't turned on is skipped without affecting the others. BSC still works without a key (public RPC).

    Advanced: your own RPC URLs

    Leave empty to use Alchemy (or the public BSC RPC when there's no key). Chrome will ask for permission to reach a custom host.

    Deep scan (launch transaction)

    Optional, off by default. When no metadata getter on an EVM token answers, look up the token's creation transaction and search its input for a link. Needs an explorer API key: Blockscout PRO (one free key for all its chains) or Etherscan API V2 (the free tier skips some chains, BSC and Base included). At most about 3 scans a second; "nothing found" is remembered for a day.
